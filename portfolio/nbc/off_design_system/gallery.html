The Milan Cortina 2026 Olympics work isn’t presented as static mockups—it's a fully structured Figma design system built for the TV Everywhere (TVE) ecosystem. The file contains component libraries, motion rules, metadata-driven template logic, and platform-specific artwork guidelines that power automated distribution across MVPD and dMVPD partners. I’m happy to walk anyone through the file live, but for now, the screen captures below highlight the scope and depth of the system—from content rails and metadata hierarchies to pictograms, artwork safe areas, program cells, and cross-platform playback UX. Each frame represents not just a visual, but a rule-driven foundation designed to scale across broadcast partners, devices, and Olympic programming.
